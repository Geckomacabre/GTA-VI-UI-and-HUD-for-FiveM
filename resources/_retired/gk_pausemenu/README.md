# gk_pausemenu (retired)

**Superseded — kept here for reference only, not maintained.** Use
[`resources/gk_pausemenu`](../../gk_pausemenu) instead.

This was the first version of the pause menu: a fully custom NUI takeover of
the native ESC menu, with a self-drawn map (real GTA V map art extracted via
`_tools/map_extract`) and a Locations panel fed by a live scan of every real
blip on the server. It was replaced by a dashboard-style pause menu whose
Map, Settings and Keybinds hand off to the real native frontend screens
instead of a custom-drawn map, which is both more accurate and less work to
keep in sync with the base game.
